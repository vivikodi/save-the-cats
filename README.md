# Save the Cat

This is a simple arcade game made with Processing (Java). The aim is to keep the cats bouncing on the paddle for as long as possible without letting them fall off the screen.

Features:
* Control the paddle with the mouse.
* Keep track of your score.
* New cats appear as you reach certain scores.
* Restart the game after a game over.

Controls:
* Mouse – Move the paddle
* Mouse Click – Start or restart the game

Built With:
* Processing (Java)

How to Run:
Open `main.pde` in Processing and click Run.

The project was created to practise programming and game development by building a simple arcade game.
